# odo-admin-react

React rewrite of the Odo admin SPA (`src/ui/odo-admin`), built in
stages. It calls the same odo APIs, and at cutover it replaces the
Angular app at `/odo/admin`. See [TODO.md](TODO.md) for what's ported.

## Stack

Vite, React 19, React Router 8 (data mode, lazy routes, middleware),
Tailwind 4, shadcn/ui (radix base), react-i18next. Design and theme
match odo-translate.

## Commands

    (cd ../core && npm ci && npm run build)   # @odo/core resolves to its dist/
    npm install
    npm run dev        # http://localhost:5173; /api proxies to the dev cluster
    npm test           # vitest
    npm run typecheck
    npm run lint
    npm run build

`/api` proxies to `http://localhost:30080` (the dev cluster's gateway);
set `ODO_API_TARGET` to point it somewhere else.

## Layout

- `src/router.tsx`: the route tree. The shell route's middleware
  requires a session, and each tool route's middleware requires the
  tool's read perm. Middleware runs before loaders, so a guarded page
  never fires API calls the user can't make.
- `src/lib/admin-tools.ts`: the tool registry. One entry wires a tool's
  routes, sidebar entry, and home card.
- `src/routes/`: one lazily loaded module per route (`loader`,
  `Component`, optional `handle` for its breadcrumb).
- `src/components/data-table/`: the shared list table and paginator.
  Columns are data (`Column<T>[]`). Sorting and paging are server-driven
  and live in the URL (`src/lib/list-state.ts`), so every list view
  deep-links. `routes/permissions` is the reference list.
- `src/api/`: typed clients. `src/api/types/` is generated by
  `scripts/generate-openapi.sh`; don't edit it.
- `src/auth/`: the session store (wraps `@odo/core`'s auth client) and
  the perm codes.
- `src/locales/en/*.json`: source strings, one namespace per file,
  loaded per route. Keys are type-checked against these files.

## Base path

The image builds with a placeholder base and substitutes
`ODO_ADMIN_BASE_PATH` (default `/odo/admin`; `/` serves at the host
root) when the container starts; see
`docker-entrypoint.d/40-base-path.sh`. The APIs are always called at
the host root. `index.html` is served with
`Cache-Control: no-cache, no-store, must-revalidate`; hashed assets
are immutable.

## Localization

English is the only real locale. The account menu also offers two
pseudo-locales: `en-XA` (accented and 30% longer, to show hard-coded
text and truncation) and `ar-XB` (mirrored right-to-left).
